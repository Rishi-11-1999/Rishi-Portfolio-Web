About

I'm a full stack developer with 3 years of experience across Angular, Node.js, and MSSQL. My work has ranged from maintaining and extending a travel booking platform that's been live in production for over a decade, to building a Learning Management System from the ground up.

I'm comfortable working inside existing, evolving codebases as much as greenfield builds — reading legacy code, fixing production bugs, and shipping new features without breaking what's already working for real users. I also handle my own deployments on Linux servers using PuTTY and WinSCP, so I'm used to owning a feature from local branch to live server.

More recently, I've been integrating the OpenAI API into Node.js backends to add AI-driven features, building a working knowledge of web security fundamentals using Burp Suite, deploying frontend projects on Vercel, and building on WordPress + Hostinger for a personal business site.
